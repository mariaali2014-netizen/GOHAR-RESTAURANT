GOOD TO KNOW

Frequently asked questions.

Can I order directly from this website?

Yes. Add items to the cart and use the WhatsApp ordering button. The order is prepared as a WhatsApp message for the restaurant.

Can the menu and prices be changed?

Yes. The menu is frontend data in app.js, so dishes, categories, prices and descriptions can be updated without changing the page structure.

Does the website work on mobile?

Yes. The layout is responsive for phones, tablets and desktop screens, including a mobile navigation menu and floating WhatsApp action.

Is a customer account required?

No. This version is intentionally frontend-only and does not require login, registration or a database.
